# 공개본 준비와 검증

## 공개 방식

공개본은 검토된 현재 파일로 시작하는 새 Git 이력이다. 기존 Replit 작업
저장소·원본 파일·이력은 보존하고, 기존 브랜치나 태그를 함께 올리지 않는다.
원본의 내부 원격 저장소를 바꾸거나 과거 이력을 재작성하지 않는다.

사용자가 승인한 GitHub 연결 프록시를 통한 업로드는 초기 `.gitignore`
커밋과 전체 소스 커밋, **총 두 개의 새 커밋**으로 시작한다. 초기화
커밋에도 비밀값이나 내부 자료는 없다. 공개 저장소의 기본 브랜치 하나만
사용하며 기존 저장소나 브랜치를 강제로 덮어쓰지 않는다.

포함: 여섯 아티팩트의 전체 소스·실행 설정, 공용 라이브러리, 생성된 API
계약 코드와 원본 OpenAPI, DB 스키마, 잠금 파일, 필요한 이미지·배경음악·
홍보 영상의 짧은 클립. `attached_assets/video-sources/kiosk-current.jpg`도 보존한다.

공개본에서만 제외:

| 항목 | 이유 |
| --- | --- |
| `.agents/`, `replit.md` | 내부 에이전트 문서·작업공간 메타데이터. 실행 정보는 루트 README에 정리 |
| `attached_assets/Pasted-*` | 붙여넣은 비실행 기획 원문 |
| `tuptalk.mp4`, `--.mp4` | 사용자 선택에 따라 루트 완성 영상 제외. 아티팩트가 참조하지 않음 |
| 발표 덱의 `EXPORT-CHECK.md` | 공개본 밖의 생성된 PDF/PPTX에 대한 내부 점검 기록 |
| `.local/`, `.cache/`, `node_modules/`, `dist/`, `generated-artifacts/` | 로컬 도구·의존성·빌드 결과·생성물 |
| `private-evaluation/`, 녹음·덤프·환경·인증·로그 파일 | 고객 데이터와 비밀정보 보호 |

`.gitignore`만으로 기존 추적 파일이나 이력을 정제할 수 없으므로
`scripts/export-public.py`로 별도 소스 복사본을 만든다. 복사본의
`.public-exportignore`는 공개 전용 제외 규칙이며 원본 삭제 명령이 아니다.

## 안전 점검의 범위

추적 파일 전체와 최종 공개 복사본을 점검한다. 알려진 공급자 키·토큰,
개인키, 인증 정보가 포함된 연결 URL, JWT, 의심스러운 고정 인증값과
민감 파일명을 검사하며 값 자체는 출력하지 않는다. 이메일·전화번호·
실제 직원 계정 ID, 녹음·DB 덤프 여부도 별도 확인한다.

공개 이력에는 승인된 현재 파일의 새 커밋만 있어야 한다. 원본의 과거 이력은 **검사
완료한 공개 이력으로 취급하지 않으며**, 어디에도 업로드하지 않는다.
자동 패턴 검사는 숨은 비밀정보·모든 개인정보·권리 문제의 부재를 보장하지 않는다.
새로 추가한 파일도 공개 전에 다시 검토해야 한다.

## 검증 결과

검사일: 2026-10-14. Replit Linux x64, Node.js 24.13.0, pnpm 10.26.1.

| 검사 | 실제 결과 |
| --- | --- |
| `pnpm install --frozen-lockfile` | 성공. 잠금 파일·의존성 버전 변경 없음. 기존 의존성 저장소를 사용한 설치 검사이며 새 기기의 무캐시 설치 검증은 아님 |
| 공용 라이브러리 `tsc --build` | 성공 (`pnpm run typecheck`의 첫 단계) |
| API·키오스크·덱·샌드박스·공용 스크립트 타입 검사 | 모두 성공 (`pnpm run typecheck` 출력에서 각각 완료 확인) |
| `pnpm --filter @workspace/api-server run test` | 97/97 성공. AI 모의 구현·테스트 전용 개발 DB 행 사용 |
| 키오스크 `test:recorder`, `test:menu`, `test:speech`, `test:analytics` | 각각 9/9, 2/2, 14/14, 12/12 성공 |
| `python -m unittest discover -s scripts -p 'test_export_public.py' -v` | 7/7 성공. 추적된 제외 파일·민감값 거절·원본 보존·기존 대상 덮어쓰기 거절 확인 |
| 전체 `pnpm run typecheck` | **실패**. 기존 홍보 영상의 DOM 타입 누락과 애니메이션 `Variant` 타입 오류 |
| `pnpm --filter @workspace/voice-kiosk-demo run typecheck` | **실패**. 기존 데모 영상에도 DOM 타입 누락과 애니메이션 `Variant` 타입 오류 |
| 키오스크 미리보기 | 첫 화면 렌더링 확인. 브라우저 콘솔에 앱 오류 없음 |
| GitHub 인증·이름 충돌 확인 | 승인된 연결 프록시에서 `minjcho` 계정 확인. 인증된 조회에서 새 저장소 없음 확인 |

영상 오류의 유형은 TS2304, TS2322, TS2584, TS2812, TS7006이다.
해당 영상 소스·TypeScript 설정은 변경하지 않았다. 전체 검사 실패를
이번 공개 준비 변경으로 해결한 것처럼 보고하지 않으며, 루트 빌드·
무캐시 설치·외부 호스팅·실제 마이크·실제 AI 호출은 검증하지 않았다.

공개용 복사본은 여섯 아티팩트와 필수 에셋을 포함하고 약 4.1MB다.
가장 큰 포함 파일은 약 561KB의 배경음악이다. 새 Git LFS 설정은 도입하지 않았다.
추적 파일 검사에서 실제 비밀값·이메일·전화번호·실제 직원 ID에 해당하는
패턴이나 DB 덤프·개인 녹음은 발견하지 못했다. 제품 화면 원본 이미지는
빈 주문 화면이며, 포함된 음성 파일은 데모·홍보 영상의 생성된 배경음악이다.

GitHub 저장소 생성·업로드 완료는 **원격의 공개 설정, 기본 브랜치,
커밋 이력과 전체 파일 내용을 대조한 뒤에만** 별도로 보고한다.
